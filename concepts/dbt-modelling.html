Concepts / dbt modelling

Transformation

dbt modelling

dbt turns warehouse data into tested reporting models with visible dependencies.

Visual model

Move logic through controlled layers.

Each layer has a clear purpose. Reporting tools read governed marts instead of rebuilding business rules.

SourceRaw tables
↓
StagingRename and standardise
↓
IntermediateApply business logic
↓
MartsServe governed metrics
↓
ConsumerPower BI

Why it matters

One metric needs one definition.

Business logic in dashboard files can become inconsistent. Governed models provide one controlled definition.

Implementation

Build and test each layer.

Model dependencies define execution order. Tests check keys, required values, and accepted relationships.

Evidence

17 models and 73 tests.

The Enterprise Spend project records the transformation and test structure.
