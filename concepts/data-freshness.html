Concepts / Data freshness

Data operations

Freshness is not the latest business date.

A historical dataset can be complete and current as a delivery even when its latest transaction date is old.

Visual model

Test recency and coverage separately.

Operational freshness checks when the pipeline loaded the data. Period completeness checks whether the declared reporting window is intact.

Operational freshness

Is the delivery current?

Measure elapsed time from the latest successful load. Do not use the transaction date as a substitute.

Period completeness

Is the declared window intact?

Test source dates, FX coverage, mart boundaries, and expected monthly partitions.

Shared contract

Calculate once.

Store monitoring facts in governed views. Dashboard tools read the result instead of rebuilding the rules.

Recovery evidence

Prove the control can fail.

The first live check detected a 243.662-hour stale load. A controlled reload restored a 6/6 pass.
