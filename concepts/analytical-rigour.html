Concepts / Analytical rigour

Statistical analysis

Challenge the result before using it.

Prevent future information from entering the model. Test whether a finding survives different assumptions and uncertain samples.

Visual model

A point estimate is not enough.

Use information available at the time, test several classifications, measure uncertainty, and compare independent implementations.

Look-ahead bias

Use only available information.

A current return cannot use a macro signal that was known only after that return.

Sensitivity testing

Change the assumptions.

Repeat the analysis across plausible thresholds and compare the conclusion.

Uncertainty

Show the range.

Bootstrap intervals show when a strong point estimate is still imprecise.

Reconciliation

Compare independent outputs.

Agreement between Python and PostgreSQL reduces implementation risk.
