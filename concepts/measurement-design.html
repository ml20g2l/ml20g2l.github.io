Concepts / Measurement design

Decision analytics

A metric needs a decision job.

A KPI measures the intended outcome. A guardrail checks that improvement does not create another problem.

Visual model

Start with the question, not the chart.

Define the decision, metric, calculation, grain, comparison, and guardrail before building the visual.

KPI definition

Remove ambiguity.

State the formula, grain, filters, time window, owner, and data source.

Driver metric

Explain the result.

Use a small set of measures that can explain why the KPI moved.

Guardrail metric

Check unintended harm.

A conversion gain is not useful if returns rise or margin falls materially.

Decision rule

Define action before the result.

State the threshold that supports rollout, review, or rejection.
